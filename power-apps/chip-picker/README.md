# Progress Step

This component provides a clean and responsive chip‑based selector that allows the user to choose a single option. It is lightweight, intuitive, and easy to integrate into any Power Apps interface.

## Minimal path to awesome

1. Open your canvas app in **Power Apps**
2. Copy the contents of the **[YAML-file](./source/chip-picker.yaml)** 
3. Paste the YAML code into the Power Apps component section, then add the component to your canvas and fill in the Items and Default properties.
