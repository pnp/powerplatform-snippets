# Sample Templates
We have multiple sample templates for the Power Platform Snippets:

Every snippet `README.md` must end with the following tracker as its final line:

```html
<img src="https://m365-visitor-stats.azurewebsites.net/powerplatform-snippets/{snippet-path}" />
```

Replace `{snippet-path}` with the repository-relative path to the snippet folder, using `/` separators and no leading or trailing slash. For example, use `power-apps/my-snippet` for a snippet stored in that folder.
